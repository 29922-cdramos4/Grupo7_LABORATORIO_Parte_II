Teoría

Tooltip y Popover: Componentes interactivos para mejorar la experiencia de usuario.

¿Qué es un Tooltip?

Un tooltip es un pequeño elemento emergente que aparece cuando el usuario coloca el cursor sobre un elemento específico. Proporciona información adicional sin ocupar espacio permanente en la interfaz.

¿Qué es un Popover?

Un popover es un contenedor más grande que aparece al hacer clic o interactuar con un elemento. A diferencia del tooltip, puede contener texto formateado, botones, imágenes y otros elementos HTML.

Diferencias principales:

  • Activación: Tooltips se activan al pasar el cursor (hover), popovers requieren clic.
  • Contenido: Tooltips contienen texto simple, popovers pueden incluir HTML complejo.
  • Duración: Tooltips desaparecen al quitar el cursor, popovers permanecen hasta ser cerrados.
  • Tamaño: Tooltips son pequeños y discretos, popovers pueden ser más grandes.

Casos de uso:

Tooltips: Explicar iconos, mostrar información adicional sobre campos de formulario, proporcionar ayuda contextual.

Popovers: Formularios pequeños, menús de configuración, información detallada, confirmaciones de acciones.

Ejemplo

Ejemplo práctico de Tooltips con Bootstrap

Código HTML:

<div class="container">
    <h1>Tooltips</h1><br>
    
    <div class="row">
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-primary btn-block" data-toggle="tooltip" 
                    data-placement="left" title="Izquierda">Presionar 1</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-primary btn-block" data-toggle="tooltip" 
                    data-placement="top" title="Superior">Presionar 2</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-primary btn-block" data-toggle="tooltip" 
                    data-placement="right" title="Derecha">Presionar 3</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-primary btn-block" data-toggle="tooltip" 
                    data-placement="bottom" title="Inferior">Presionar 4</button>
        </div>
    </div>
</div>

Demostración en vivo:

Haz clic para activar/desactivar tooltips. Cuando estén activos, pasa el cursor sobre los botones azules

Código HTML para Popovers:

<div class="container">
    <h1>Popover</h1><br>
    
    <div class="row">
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-info btn-block" data-container="body" 
                    data-toggle="popover" data-placement="left" data-content="Lorem">Presionar 1</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-info btn-block" data-container="body" 
                    data-toggle="popover" data-placement="top" data-content="Lorem">Presionar 2</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-info btn-block" data-container="body" 
                    data-toggle="popover" data-placement="right" data-content="Lorem">Presionar 3</button>
        </div>
        <div class="col-xs-12 col-sm-3">
            <button class="btn btn-info btn-block" data-container="body" 
                    data-toggle="popover" data-placement="bottom" data-content="Lorem">Presionar 4</button>
        </div>
    </div>
</div>

Demostración de Popovers:

Haz clic para activar/desactivar popovers. Cuando estén activos, haz clic en los botones naranjas

Ejercicio y Sugerencias

Formulario interactivo con tooltips y popovers aplicados - ¡Practica lo aprendido!

Código HTML del Formulario con Tooltips y Popovers:
<form>
    <div class="mb-3">
        <label class="form-label">
            Nombre 
            <i class="fas fa-info-circle" data-bs-toggle="tooltip" 
               data-bs-placement="top" title="Ingresa tu nombre completo"></i>
        </label>
        <input type="text" placeholder="Nombre" class="form-control" 
               data-bs-container="body" data-bs-toggle="popover" data-bs-placement="right" 
               title="Ayuda para Nombre" 
               data-bs-content="Escribe tu nombre y apellido. Mínimo 2 caracteres.">
    </div>

    <div class="mb-3">
        <label class="form-label">
            Correo Electrónico 
            <i class="fas fa-info-circle" data-bs-toggle="tooltip" 
               data-bs-placement="top" title="Debe ser un email válido"></i>
        </label>
        <input type="email" placeholder="correo@ejemplo.com" class="form-control" 
               data-bs-container="body" data-bs-toggle="popover" data-bs-placement="left" 
               title="Formato de Email" 
               data-bs-content="Ejemplo: usuario@dominio.com">
    </div>

    <div class="mb-3">
        <label class="form-label">
            Mensaje 
            <i class="fas fa-info-circle" data-bs-toggle="tooltip" 
               data-bs-placement="top" title="Comparte tus ideas sobre fútbol"></i>
        </label>
        <textarea rows="5" placeholder="Escribe tu mensaje aquí..." 
                  class="form-control" data-bs-container="body" data-bs-toggle="popover" 
                  data-bs-placement="bottom" title="Consejos para el Mensaje" 
                  data-bs-content="Máximo 500 caracteres. Puedes comentar sobre partidos, árbitros, equipos, etc."></textarea>
    </div>

    <button type="submit" class="btn btn-primary w-100" 
            data-bs-toggle="tooltip" data-bs-placement="top" 
            title="Envía tu formulario completo">
        Enviar Sugerencia
    </button>
</form>
